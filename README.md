# Heartline 8:08 — AquiraCraft

A personalized Valentine Week broadcast with a creator studio and eight distinct, multi-stage recipient experiences.

## Run locally

```bash
npm install
npm run dev
```

## Production checks

```bash
npm run lint
npm run build
```

Creator details are encoded into the generated share URL; no account or backend is required. Recipient discovery progress is stored locally in the browser.
